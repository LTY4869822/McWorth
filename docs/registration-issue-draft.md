**正文**：

【参赛申请】

项目名称：麦麦如意餐 McWorth

项目地址：https://github.com/<你的用户名>/McWorth

项目简介：McWorth 是一个基于麦当劳官方 MCP 服务器的餐饮配餐 Skill，帮你回答一个真实痛点：同样的预算，怎么点才最划算？它支持两种模式——给定预算反推最优组合（如"30 元吃到最饱"），或指定餐盘求解最省价格。核心亮点源于真实发现：官方菜单上"中薯+可乐"与"中薯+零度可乐"标价相反，McWorth 通过枚举全部合法组合，能找出"多加一杯可乐反而便宜 ¥2.50"这类反直觉最优解。技术上，Skill 固化了一套可审计的取价管线：菜单快照 → 官方 calculate-price 逐单核价 → 报价身份四元组校验（request_id/session_id/intent_revision/context_key）→ 6 小时新鲜度门槛，报告明确区分 live / 历史回放 / 合成三种数据来源并逐条披露被拒报价，杜绝"看起来便宜实际核不了价"的假优化。内置 57 个回归测试，覆盖单选上限、凑单回退、越界身份拒绝等工作流边界；通过真实 MCP 在线只读验收（全链路 traceId 可查）。MIT 开源，即装即用。
